# Pizza-Sales-Analytics-Dashboard-using-MySQL-and-Microsoft-Excel
Developed an interactive pizza sales analytics dashboard using MySQL and Microsoft Excel to analyze sales performance, customer ordering patterns, product demand, and revenue trends. Extracted and transformed transactional data using SQL and converted analytical results into KPI-driven Excel dashboards to support data-based business decisions.
Developed a **MySQL + Excel sales analytics dashboard** to evaluate revenue, order volume, product performance, and customer ordering trends.
Used **SQL queries, aggregation, data cleaning, and KPI analysis** to identify top/bottom-performing pizzas, category-wise sales, size-wise demand, and temporal sales patterns.
Built an interactive **Excel dashboard with KPI cards, charts, and filters** to generate actionable insights for **sales optimization, inventory planning, and strategic decision-making**.
